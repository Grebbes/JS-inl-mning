# The Town adventure

## Text based adventure game
<li>This is game i made for a school project, really fun and learned allot</li>
<li>The game is a text based clicking game.</li>
<li>You are able to fight monsters buy new weapons and potions, and eventually kill the boss!</li>

## Features
<li>Click based gameplay</li>
<li>fight different monsters</li>
<li>buy weapons, armour and health potions</li>
<li>get experience</li>

## How to play
Use your mouse and click on the different options that appear nothing super fancy. This is my first game
